# Учебный интернет-магазин

Практические работы №1–6 по дисциплине «Фронтенд и бэкенд разработка».

## Запуск

Открыть `index.html` в браузере. Установка зависимостей не требуется.

## Структура

- `index.html` — главная страница;
- `css/style.css` — оформление страниц;
- `images/` — папка для изображений;
- `.gitignore` — исключения для Git.

## Технологии

HTML, CSS, Git и GitHub Pages.

## Выполненные работы

1. Создана структура проекта и настроена работа с Git.

## Проверка

1. Открыть главную страницу и проверить ссылки на разделы.

## Текущий статус

Создана базовая структура проекта.

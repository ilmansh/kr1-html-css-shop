## Запуск

Открыть `index.html` в браузере. Установка зависимостей не требуется.

GitHub Pages: https://ilmansh.github.io/kr1-html-css-shop/

## Структура

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контакты и переход к форме заявки;
- `css/style.css` — оформление страниц;
- `js/main.js` — модальное окно и проверка формы;
- `images/` — папка для изображений;
- `.gitignore` — исключения для Git.

## Технологии

HTML, CSS, JavaScript, Git и GitHub Pages.

Тема: «HTML и CSS: разработка многостраничного сайта». Основа проекта — семантическая разметка, внешний CSS и навигация между страницами. В этом репозитории выполнены этапы из практических работ №1–5.

## Форма заявки

Кнопка «Заказать» передаёт название товара в скрытое поле и открывает `dialog`. Проверяются обязательные поля, длина имени, e-mail, формат телефона и согласие. После успешной проверки форма очищается, окно закрывается и появляется сообщение об успехе. Отправки на сервер нет.

Телефон вводится в формате `+7 (900) 000-00-00`.

## Стили

В `:root` заданы цвета, отступы, скругления и ширина контента. Есть состояния `:hover`, `:focus-visible`, `:disabled`, а ошибочные поля выделяются по `aria-invalid`.

## Навигация

На всех страницах одинаковое меню. Ссылки `index.html#advantages`, `index.html#popular` и `index.html#contacts` ведут к разделам главной. На внутренних страницах есть хлебные крошки. У каждой страницы свои `title` и `meta description`.

## Проверка

1. Открыть главную страницу и проверить ссылки на разделы.
2. Открыть форму кнопкой «Заказать», проверить пустые поля, неверный e-mail и телефон.
3. Заполнить форму правильно и проверить сообщение об успехе.
4. Перейти в каталог и контакты, проверить меню и хлебные крошки.

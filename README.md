## Форма заявки

Кнопка «Заказать» передаёт название товара в скрытое поле и открывает `dialog`. Проверяются обязательные поля, длина имени, e-mail, формат телефона и согласие. После успешной проверки форма очищается, окно закрывается и появляется сообщение об успехе. Отправки на сервер нет.

Телефон вводится в формате `+7 (900) 000-00-00`.

## Стили

В `:root` заданы цвета, отступы, скругления и ширина контента. Есть состояния `:hover`, `:focus-visible`, `:disabled`, а ошибочные поля выделяются по `aria-invalid`.

## Навигация

На всех страницах одинаковое меню. В каталоге есть переходы к категориям, из карточек — к характеристикам товара, затем к заявке. В подвале находятся ссылки на разделы главной и вопросы о заказе. На внутренних страницах есть хлебные крошки. У каждой страницы свои `title` и `meta description`.

## Flexbox и Grid

- `.site-nav__list` — Flexbox для меню, перенос пунктов через `flex-wrap`.
- `.product-card` — вертикальный Flexbox, кнопка прижата вниз через `margin-top: auto`.
- `.products-grid` — сетка карточек через `repeat(auto-fit, minmax(180px, 1fr))`.
- `.catalog-layout` — колонки `240px` и `minmax(0, 1fr)`, области `filters` и `products`.
- `.filters-form` — Grid для расположения групп фильтра.

Фильтр по цене показывает подходящие товары, кнопка «Сбросить» возвращает весь каталог. Отдельная мобильная версия пока не реализована.

На странице заявки выбираются товар, количество и способ получения. Курьерская доставка стоит 300 ₽, самовывоз бесплатный. Перед подтверждением открывается окно проверки данных. Заявка обрабатывается только в браузере.

2. Открыть форму кнопкой «Заказать», проверить пустые поля, неверный e-mail и телефон.

4. Перейти в каталог и контакты, проверить меню и хлебные крошки.
5. В DevTools проверить `display: flex`, `display: grid`, `gap` и именованные области каталога.

## БЭМ

Блоки: `site-header`, `site-nav`, `product-card`, `breadcrumbs`, `order-form`, `order-dialog`.

Элементы: `site-nav__link`, `product-card__title`, `product-card__price`, `order-form__input`. Модификаторы: `site-nav__link--active`, `button--primary`, `button--secondary`.

Стили компонентов заданы через классы. `id` оставлены для якорей, подписей полей и JavaScript. Кнопка «Наверх», форма и раскладка страниц сохранены.

## Практическая №7 — что сделано

Навигация, карточки, форма, модальное окно и хлебные крошки оформлены как самостоятельные БЭМ-блоки. Двойное подчёркивание отделяет элемент от блока (`product-card__title`), двойной дефис обозначает вариант (`button--secondary`). Классы в HTML согласованы с CSS; JavaScript находит элементы по `id` и `data-product`, поэтому переименование классов не меняет работу формы.

### Четыре финальные доработки

1. `.product-card` получила `position: relative`: карточка стала системой отсчёта для бейджа.
2. `.product-card__badge` получила `position: absolute`: метки «Хит» и «Новинка» расположены в правом верхнем углу карточек главной и каталога. Модификатор `product-card--badged` резервирует место над заголовком, а `product-card--featured` выделяет карточку хита рамкой. Метки демонстрационные, как и товары учебного магазина.
3. `.catalog-filters` получила `position: sticky` и отступ `top`: фильтр остаётся у верхнего края при прокрутке в пределах каталога. Максимальная высота ограничена окном браузера, содержимое при необходимости прокручивается.
4. README дополнен сопоставлением требований с файлами, пояснениями для защиты и шагами проверки.

Ранее реализованная `.back-to-top` использует `position: fixed` и `z-index: 1000`. Она закреплена относительно окна браузера. Модальный `dialog`, открытый через `showModal()`, отображается в верхнем слое браузера над обычными элементами страницы.

### Как показать позиционирование

1. Открыть главную: у блокнота виден бейдж «Хит», у органайзера — «Новинка». Заголовки не перекрыты.
2. В DevTools проверить `position: relative` у карточки и `position: absolute` у бейджа.
3. Открыть каталог и прокрутить страницу: фильтр закрепляется с отступом 24 px, затем останавливается у нижнего края каталога.
4. Проверить фильтр: диапазон 1200–1800 показывает органайзер; сброс возвращает три товара.
5. На главной прокрутить вниз и нажать «Наверх»; открыть форму заказа и убедиться, что диалог находится поверх кнопки.
6. Открыть товар, перейти к заявке, проверить пустую форму, затем заполнить её и подтвердить учебную заявку.
